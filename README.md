# 📈 AI-Powered Stock Analysis & Prediction Dashboard

A desktop application that combines LSTM neural networks, Linear Regression, live market data, and an AI chatbot to analyse and forecast stock prices — all in one interface.

---

## What It Does

- **Live Stock Data** — Fetches real-time historical price data for any ticker (e.g. AAPL, TSLA) using Yahoo Finance
- **Dual Model Forecasting** — Predicts future closing prices using both an LSTM neural network and Linear Regression, plotted side-by-side
- **30-Day SMA** — Overlays a Simple Moving Average on the chart to show trend direction
- **News Feed** — Pulls the 5 latest news headlines for the selected stock via NewsAPI
- **AI Financial Chatbot** — Answers user questions about finance using Google Gemini
- **Price Alerts** — Notifies the user when a stock hits a user-defined target price

## Project Structure

```
stock-price-prediction/
│
├── financial_assistant.py   # Main GUI application (run this)
├── train_lstm.py            # Script to train and save the LSTM model
├── lstm_model.h5            # Pre-trained LSTM model (generated by train_lstm.py)
├── scaler.pkl               # Fitted MinMaxScaler (generated by train_lstm.py)
├── .env                     # API keys (not committed — see .env.example)
├── .env.example             # Template for required environment variables
└── requirements.txt         # Python dependencies
```

## How to Run

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/stock-price-prediction.git
cd stock-price-prediction
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set up API keys
Copy `.env.example` to `.env` and fill in your keys:
```bash
cp .env.example .env
```

```
GEMINI_API_KEY=your_google_gemini_api_key
NEWS_API_KEY=your_newsapi_key
```

- Get a free Gemini API key at: https://aistudio.google.com/
- Get a free NewsAPI key at: https://newsapi.org/

### 4. Train the LSTM model (first time only)
```bash
python train_lstm.py
```
This downloads AAPL data, trains the model, and saves `lstm_model.h5` and `scaler.pkl`.

### 5. Run the app
```bash
python financial_assistant.py
```

## Key Design Decisions

- **Two-model approach** — LSTM captures non-linear temporal patterns; Linear Regression provides a simpler trend baseline. Comparing both gives more context than a single model.
- **Separate training script** — `train_lstm.py` is kept separate so the model is trained once and loaded at runtime, keeping the GUI fast.
- **Threading** — Gemini API calls run in a background thread to keep the UI responsive.
- **Scaler persistence** — The MinMaxScaler fitted during training is saved and reloaded during inference to prevent data leakage.

---

## Limitations

- LSTM is currently trained on AAPL only. To predict other stocks, retrain `train_lstm.py` with the desired ticker.
- Predictions are for educational/learning purposes and not financial advice.
